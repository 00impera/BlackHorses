🧰 Flutter SDK Installation Checklist

✅ 1. System Requirements
Make sure your device meets these minimum specs:
- OS: Windows 10/11, macOS 10.15+, or any 64-bit Linux distro
- RAM: At least 8 GB (16 GB recommended)
- Storage: 4 GB free for SDK + more for IDE/emulators
- Processor: Intel i5 or better

---

🛠️ 2. Install These Tools

| Tool                  | Purpose                                      | How to Get It                          |
|-----------------------|----------------------------------------------|----------------------------------------|
| Flutter SDK       | Core framework for building apps             | Download from Flutter.dev |
| Dart SDK          | Programming language used by Flutter         | Comes bundled with Flutter             |
| Android Studio    | IDE + Android emulator                       | Install Android Studio |
| VS Code (optional)| Lightweight editor with Flutter extensions   | Install VS Code |
| Git               | Version control and Flutter setup            | Install Git    |

---

🔍 3. Run Flutter Doctor
After installing everything, open your terminal and run:

`bash
flutter doctor
`

This command checks your setup and tells you what’s missing (like Android SDK, emulator, etc.). Fix any issues it flags before moving on.

---

📦 4. Set Up Emulator or Device
- Use Android Studio to create a virtual device
- Or connect a physical Android phone with USB debugging enabled
